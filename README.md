# AI Lab 도우미 다운로드

현재 AI Lab 운영 웹은 새 도우미 연결 화면을 게시하기 전입니다. 설치 파일은 받을 수 있지만 웹 연결·실물 업로드는 웹 업데이트 후 확인합니다.

AI Lab 웹 화면에서 Arduino 호환 보드를 연결할 때 사용하는 Windows 10/11 64비트용 도우미입니다. 기존 Arduino Bridge 0.12.2와 별도로 설치됩니다.

**0.12.3 설치 파일:** [AI-Lab-Helper-Setup-0.12.3.exe](https://github.com/zcrong01/ai-lab-helper-downloads/releases/download/v0.12.3/AI-Lab-Helper-Setup-0.12.3.exe)
**파일 크기:** 9,817,646바이트
**SHA256:** `388D8011385456EAB9553778C65E017EDE9674083C2E630D0D19CDC5C9CD2EDB`

1. 공식 [AI Lab 웹 화면](https://withseok-edulab.web.app/tools/arduino/)에서 도우미 설치 안내를 엽니다.
2. 위 고정 버전의 파일명과 SHA256을 확인한 뒤 설치합니다. 이 버전은 **코드 서명이 없습니다**. Windows 보안 경고가 나오면 보안 검사를 우회하지 말고 제공자에게 문의하세요.
3. 웹 연결 승인창에 `https://withseok-edulab.web.app`가 표시되는지 확인한 뒤 허용합니다.
4. 필요한 경우 컴파일 환경을 준비하고 보드·포트를 선택합니다. 업로드 뒤 실제 보드의 동작은 별도로 확인해야 합니다.

작품은 웹의 저장 기능으로 JSON 파일을 따로 보관하세요. Python·PyInstaller·Tcl/Tk 관련 고지는 [THIRD_PARTY_NOTICES.txt](THIRD_PARTY_NOTICES.txt)에 있습니다. Arduino CLI·AVR 도구와 선택적 CH340 드라이버는 설치 파일에 포함되지 않고 필요 시 별도로 다운로드됩니다.

이 저장소는 공개 설치 파일·해시·안내 전용입니다. 제품 소스·회원 자료·시험 기록을 담지 않습니다.
